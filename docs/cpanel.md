# راهنمای نصب روی هاست cPanel (Node.js App + MySQL)

این بسته شامل سایت سه‌زبانه، حساب کاربری مشتری و پنل مدیریت است و روی «Setup Node.js App» در cPanel اجرا می‌شود. نیازی به اجرای `npm install` یا build روی هاست نیست.

**پیش‌نیاز:** Node.js نسخهٔ ۱۸٫۱۸ یا بالاتر (ترجیحاً ۲۰ یا ۲۲) · MySQL 8 یا MariaDB 10.5+ · دست‌کم ۱ گیگابایت RAM برای برنامه.

---

## ۱. ساخت پایگاه داده
1. در cPanel به **MySQL® Databases** بروید.
2. یک پایگاه داده بسازید (مثلاً `cpuser_eno`).
3. یک کاربر با رمز قوی بسازید (مثلاً `cpuser_eno`).
4. در بخش **Add User To Database** کاربر را به پایگاه داده اضافه کنید و **ALL PRIVILEGES** را بدهید.

جدول‌ها هنگام اولین اجرای برنامه خودکار ساخته می‌شوند؛ در phpMyAdmin کاری لازم نیست.

## ۲. آپلود فایل‌ها
1. در **File Manager**، فایل `enodigital-cpanel.zip` را در **پوشهٔ اصلی حساب** (نه داخل `public_html`) آپلود کنید.
2. روی فایل راست‌کلیک ← **Extract**. پوشه‌ای به نام `enodigital` ساخته می‌شود.

## ۳. تنظیمات
در پوشهٔ `enodigital` فایل `.env.example` را به `.env` تغییر نام دهید (برای دیدن فایل‌های نقطه‌دار: Settings ← Show Hidden Files) و ویرایش کنید:

| متغیر | مقدار |
|---|---|
| `APP_URL` | آدرس کامل سایت، مثل `https://enodigital.ir` |
| `DATABASE_URL` | `mysql://کاربر:رمز@localhost:3306/نام_پایگاه_داده` |
| `ZARINPAL_MERCHANT_ID` | مرچنت‌کد زرین‌پال |
| `KAVENEGAR_*` | کلید و قالب‌های پیامک (اختیاری) |

اگر رمز پایگاه داده نویسه‌هایی مثل `@ : / # ?` دارد، آن‌ها را کدگذاری کنید (`@` ← `%40`، `#` ← `%23`) یا رمزی بدون این نویسه‌ها بسازید.

> به‌جای فایل `.env` می‌توانید همین متغیرها را در صفحهٔ Node.js App در بخش **Environment variables** وارد کنید.

## ۴. ساخت برنامه در cPanel
در **Setup Node.js App** روی **Create Application** بزنید:

| گزینه | مقدار |
|---|---|
| Node.js version | بالاترین نسخهٔ موجود (۲۰ یا ۲۲) |
| Application mode | Production |
| Application root | `enodigital` |
| Application URL | دامنهٔ سایت |
| Application startup file | `app.js` |

**Create** و سپس **Restart** را بزنید. دکمهٔ «Run NPM Install» لازم نیست.

اولین بازدید از هر صفحه چند ثانیه طول می‌کشد (صفحه ساخته و ذخیره می‌شود)؛ بازدیدهای بعدی سریع‌اند.

## ۵. HTTPS
در **SSL/TLS Status** گواهی رایگان (AutoSSL / Let's Encrypt) را برای دامنه فعال کنید و در **Domains** گزینهٔ **Force HTTPS Redirect** را روشن کنید. ورود به حساب‌ها فقط روی HTTPS کار می‌کند.

## ۶. شروع کار
1. **بلافاصله بعد از نصب** به `https://دامنه/admin/` بروید. چون هنوز مدیری وجود ندارد، صفحهٔ **راه‌اندازی** باز می‌شود: نام، شمارهٔ موبایل و رمز مدیر کل را وارد کنید. این اطلاعات در پایگاه داده ذخیره می‌شود (رمز به‌صورت رمزنگاری‌شده) و صفحهٔ راه‌اندازی پس از آن بسته می‌شود. شماره و رمز بعداً از **حساب من** در پنل عوض می‌شود.
2. **تنظیمات فروشگاه**: اطلاعات فروشنده روی صورت‌حساب، درصد مالیات و **نرخ دلار** (اگر قیمتی را دلاری می‌گذارید).
3. **محصولات و پلن‌ها**: برای هر محصول پلن و قیمت (تومانی یا دلاری) تعریف کنید؛ پس از آن، بخش قیمت‌ها روی سایت نمایش داده می‌شود.
4. **خدمات دیجیتال**: دسته‌ها (مثلاً طراحی سایت، سئو) و خدمات هر دسته را با قیمت بسازید؛ در صفحهٔ «خدمات دیجیتال» سایت نمایش داده می‌شوند.
5. در پنل زرین‌پال، دامنهٔ سایت را ثبت کنید. آدرس بازگشت خودکار است: `APP_URL/api/payments/callback/`.
6. یک خرید آزمایشی با مبلغ کم انجام دهید.

### قیمت دلاری
در فرم پلن یا خدمت، «واحد پول» را **دلار آمریکا** بگذارید و قیمت را به دلار وارد کنید (مثلاً `49.99`). در سایت و هنگام خرید، مبلغ با نرخ دلار «تنظیمات فروشگاه» به تومان تبدیل و به بالا گرد می‌شود و مشتری به تومان پرداخت می‌کند. نرخ استفاده‌شده روی هر سفارش ثبت می‌شود و با تغییر نرخ، سفارش‌های قبلی عوض نمی‌شوند. تا نرخ تعیین نشده، کالاهای دلاری قابل خرید نیستند.

## به‌روزرسانی
1. فایل zip جدید را آپلود و در همان مکان Extract کنید (فایل `.env` شما دست نمی‌خورد).
2. در Setup Node.js App روی **Restart** بزنید. تغییرات پایگاه داده خودکار اعمال می‌شود.

## پشتیبان‌گیری
از **Backup** در cPanel یا **phpMyAdmin ← Export** برای پایگاه داده استفاده کنید. همهٔ سفارش‌ها و مشتریان در پایگاه داده‌اند.

## رفع اشکال
- **اگر برنامه اجرا نشود**، به‌جای خطای ۵۰۰ یک صفحهٔ «سایت اِنو دیجیتال اجرا نشد» با علت و راه‌حل در مرورگر می‌بینید (نسخهٔ قدیمی Node.js، فایل‌های ناقص، کمبود حافظه یا خطای شروع).
- **مشکل پایگاه داده** را با باز کردن `/admin/` ببینید؛ علت و راه‌حل همان‌جا نوشته می‌شود.
- **لاگ‌ها:** فایل `enodigital/logs/app.log` (در File Manager، Show Hidden Files لازم نیست). همهٔ خروجی برنامه با تاریخ و ساعت در آن نوشته می‌شود؛ خطوط `[startup]` و `[setup]` وضعیت شروع و پایگاه داده را می‌گویند.
- **اگر نه صفحهٔ راهنما می‌آید و نه `logs/app.log` ساخته می‌شود**، cPanel اصلاً `app.js` را اجرا نکرده است: در Setup Node.js App بررسی کنید Application root دقیقاً `enodigital` و Application startup file دقیقاً `app.js` باشد، سپس Restart بزنید.
- **`[setup] … ER_ACCESS_DENIED`**: نام کاربری/رمز در `DATABASE_URL` یا دسترسی کاربر به پایگاه داده.
- **`ECONNREFUSED`**: به‌جای `localhost` مقدار `127.0.0.1` (یا برعکس) را امتحان کنید.
- **صفحهٔ «Incomplete response» یا قطع شدن برنامه:** معمولاً کمبود حافظه است؛ از پشتیبانی هاست سهمیهٔ RAM بیشتر بخواهید.
- **حروف فارسی به‌شکل ؟؟؟:** پایگاه داده باید `utf8mb4` باشد؛ برنامه هنگام شروع آن را تنظیم می‌کند، ولی اگر کاربر اجازهٔ ALTER نداشته باشد، از پشتیبانی هاست بخواهید.
