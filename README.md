# وب‌سایت اِنو دیجیتال

وب‌سایت معرفی شرکت و سه محصول آن: **لیموسی**، **لیموجت** (فروش آنلاین مواد غذایی) و **سامانهٔ بن الکترونیکی رفاهیات**.

سایت ایستا (HTML/CSS/JS بدون نیاز به build)، راست‌چین، با فونت وزیرمتن و واکنش‌گرا برای موبایل.

## ساختار

```
index.html              صفحهٔ اصلی (هیرو، مسیر سه‌محصولی، درباره ما، FAQ، فرم تماس)
products/limoc.html     صفحهٔ لیموسی
products/limoojet.html  صفحهٔ لیموجت
products/refah.html     صفحهٔ سامانهٔ بن الکترونیکی رفاهیات
assets/css/style.css    استایل‌ها (رنگ هر محصول در :root تعریف شده)
assets/js/main.js       ماکاپ‌های محصولات، منو، تب‌ها، انیمیشن‌ها و مسیر خط‌چین
```

## اجرای محلی

```bash
python3 -m http.server 8000
```

سپس `http://localhost:8000` را باز کنید.
